# Outlook werkt niet goed

## Controleer eerst Outlook in de browser
Open Outlook op het web (outlook.office.com) en log in met je werkaccount.
- Werkt je e-mail daar wél? Dan ligt het aan de Outlook-app op je computer; volg de stappen hieronder.
- Werkt het daar ook niet? Dan kan het een storing zijn. Maak een ticket aan, dan kijken we ernaar.

## Basisstappen voor de Outlook-app
1. Werk Outlook bij: in Outlook naar Bestand → Office-account → Updateopties → Nu bijwerken.
2. Start Outlook in de veilige modus om te testen of een invoegtoepassing de oorzaak is:
   druk Windows-toets + R, typ `outlook.exe /safe` en druk op Enter.
3. Werkt Outlook in de veilige modus wel? Schakel dan je invoegtoepassingen
   (add-ins) één voor één uit via Bestand → Opties → Invoegtoepassingen.

## Snelle reparatie van Office
Ga naar Instellingen → Apps → Microsoft 365 → Wijzigen → Snelle reparatie. Dit
duurt enkele minuten en heeft geen internet nodig. Start daarna je computer opnieuw op.

## Gedeelde mailbox mist of werkt niet
Lukt het niet om bij een gedeelde mailbox te komen, dan kan het aan de toegang
liggen. Maak hiervoor een ticket aan, dan regelen we de juiste rechten.
